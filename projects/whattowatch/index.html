Highlights

What makes this interesting

  • Zero third-party Swift dependencies — networking, state management, and persistence all built with first-party Apple frameworks (URLSession, @Observable, SwiftData)
  • Actor-isolated networking — SupabaseClient uses Swift’s actor model to guarantee thread-safe HTTP access without manual locking
  • Parallel structured concurrency — async let loads Top 10, Trending, and Newly Added categories simultaneously on launch
  • SwiftData persistence — user’s watchlist stored locally with @Model and @Query, background metadata refresh on appear
  • Top Shelf extension — TVServices carousel surfaces trending content on the Apple TV home screen with deep-link navigation into the app
  • Batched upserts with deduplication — unique constraint on (title, platform, category) prevents duplicates; 50-row batch writes for throughput
  • Multi-source enrichment — OMDb for primary RT scores, Playwright headless scraper as fallback, ensuring high data coverage
  • Nightly CI/CD pipeline — GitHub Actions cron job provisions Chromium, runs the full pipeline, and refreshes the catalog automatically
